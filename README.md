El presente fortk tiene como finalidad ayudar a las personas uq requieran adaptar el proyecto a su Arduino uno y no tengan adaptador I2C. Es un  proyecto activo para mi laboratorio de microsoldadura. La simulación es partical y los cambios van enfocados de momento a la interfaz estrcictamente. 
Las instrucciones originales de los pines y todo lo demás las pueden encontrar en https://www.instructables.com/DIY-SMD-REWORK-STATION/
En el proyecto actual en la simulación los pines que cambiarán serán relativos a la pantalla y el encoder principalmente.
